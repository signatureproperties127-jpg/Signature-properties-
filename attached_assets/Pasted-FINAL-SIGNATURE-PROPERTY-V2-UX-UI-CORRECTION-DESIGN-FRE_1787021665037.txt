3. CRITICAL RULE — UPDATE VS NEW REQUIREMENT
========================================================

This is the most important business rule.

A) SAME REQUIREMENT:

If the client is talking about the SAME property need and changes/adds
information, use:

UPDATE REQUIREMENT

Examples:

3 BHK → 2 BHK
₹2 Cr → ₹80 Lakh
Vesu → Vesu + Adajan
Possession changed
Parking added
Furnishing changed
Facing changed
Area changed
Urgency changed

All of these MUST update the SAME RequirementID.

Example:

R000001

must remain:

R000001

Do NOT create R000002.

--------------------------------------------------------

B) NEW REQUIREMENT:

If the SAME CLIENT has a genuinely DIFFERENT property/business need,
use:

+ NEW REQUIREMENT

Examples:

Existing:
Purchase → Residential → 2 BHK → ₹80L

Client later says:
"I also need a commercial office."

Create:

R000002

Another example:

Existing:
Purchase → Residential

Client later says:
"I also want a rental flat."

Create a new Requirement.

--------------------------------------------------------

HARD RULE:

SAME NEED = UPDATE REQUIREMENT

NEW/DISTINCT NEED = NEW REQUIREMENT

Never confuse these two actions.
